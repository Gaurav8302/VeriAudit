# Implementation Plan

The 8-hour execution plan, revised against what the repository inspection and
the SDK investigation actually found.

**Decision rule for every choice (guideline §19):** does this improve the
judge-facing core experience, or make the CooL integration stronger? If neither,
do not build it.

---

## What discovery changed about the plan

Five findings that reshaped the work before it started:

1. **Phase 1 is already done.** Real `record` → real receipt → real verification
   is `CONFIRMED` working, with an 18-case tamper matrix, in `cool-proof/`. The
   guideline's "stop if this does not work" gate has been cleared, so Milestone 1
   becomes *"prove it on Vercel"* rather than *"prove it at all"*.
2. **`software.digest` must be explicit or every receipt fails verification.**
   The most likely way to ship a broken demo. Encoded in the adapter on the first
   commit and guarded by test C4.
3. **`verdict.ok` is not enough.** A stripped inclusion proof and a
   foreign-plane forgery both return `ok: true`. Verification needs pinning and
   an `inclusion === "pass"` check. Budgeted as real work, not a detail.
4. **No database is needed.** Deterministic keys + self-contained receipts + a
   rehydratable transparency log remove an entire workstream and a provisioning
   step.
5. **Receipts cost 30 KB and 17 ms each.** So nine events are CooL-backed, not
   fifty-five — which also removes ~1.6 MB of transfer and ~900 ms of signing.

## Risk register

| Risk | Probability | Impact | Mitigation |
|---|---|---|---|
| `cool-nwc` misbehaves on Vercel's Node runtime | low | **fatal** | resolved in Milestone 1, hour 1, before any UI |
| `software.digest` omitted somewhere → silent verification failure | **medium** | high | set in one place in the adapter; test C4 |
| Displaying VERIFIED when verification did not fully pass | medium | high — dishonest | tests V4 and V8; the `IntegrityState` mapper is the only path to a verified badge |
| The trail UI eats the schedule | **medium** | high | fixed 8-node layout, no graph library, hard 1-hour box |
| Search misses the hero audit under a rephrased query | low | high | authored tags + 8 asserted queries + visible suggestion chips |
| Receipt size degrades the UI | low | medium | compact references in lists; receipts fetched on demand |
| `COOL_IMAGE_DIGEST` drift breaks all verification | low | high | startup assertion + test C12 |
| Scope creep into P1/P2 | **high** | high | the hour-6 hard gate |
| IndexedDB unavailable (private mode) | low | low | in-memory fallback, honestly labelled |
